# 🚀 Exercícios de Lógica de Programação

Bem-vindo(a)! 🚀 Neste repositório, você encontrará mais de **150 exercícios** de lógica de programação, todos solucionados por mim ao longo dos meus estudos. Este repositório foi criado com o objetivo de compartilhar alguns dos exercícios que me ajudaram nessa jornada, para que eles também possam auxiliar outros iniciantes na programação a praticar, aprimorar suas habilidades e ganhar mais confiança na resolução de problemas. 💡

Você pode usar os códigos como referência para entender o raciocínio por trás de cada solução e, se quiser um desafio extra, tentar replicá-los à sua própria maneira! 🧠 Assim, você desenvolve seu próprio estilo de programação enquanto fortalece sua lógica e criatividade. 🖥️🔥

## 🖥️ Como executar os algoritmos
Os exercícios foram desenvolvidos em **Portugol**, uma pseudolinguagem utilizada para ensinar lógica de programação de forma intuitiva e estruturada. Para executá-los, você pode usar o **VisualG**, um interpretador gratuito que permite rodar e testar códigos escritos em Portugol de maneira prática.

### 🔹 Instalação do VisualG
1. Baixe o **VisualG** [neste link](https://sourceforge.net/projects/visualg30/).
2. Instale o software seguindo as instruções.
3. Abra um arquivo, por exemplo `olaMundo.alg`, digite seu código e execute o pressionando `F9`.

### 🔹 Executando no VS Code
Se você prefere utilizar o **Visual Studio Code**, há uma extensão chamada **Design Líquido** que reconhece a linguagem Portugol:
1. Abra o **VS Code**.
2. Vá até a aba de extensões (`Ctrl + Shift + X`).
3. Busque por `Design Líquido` e instale a extensão.
4. Agora você pode escrever seus algoritmos diretamente no VS Code! 🚀
   
---
#### ⚠️Observação: A maioria dos códigos foram digitados sem o uso de caracteres especiais, como ç, ^, ~, para evitar possíveis problemas de compatibilidade com o VisualG, garantindo que possam ser executados sem erros relacionados à codificação de caracteres.

## 🤝 Como Contribuir
Quer  adicionar mais códigos e ajudar este repositório a se tornar ainda mais útil? Veja como contribuir:

1. **Faça um Fork do repositório**.
2. **Crie uma branch** para suas modificações:
   ```bash
   git checkout -b minha-contribuicao
   ```
3. **Adicione novos exercícios ou melhorias**.
4. **Faça um commit com uma mensagem clara**:
   ```bash
   git commit -m "Adicionado exercício sobre laços de repetição"
   ```
5. **Envie as alterações para o seu fork**:
   ```bash
   git push origin minha-contribuicao
   ```
6. **Abra um Pull Request** e aguarde a revisão!

VISÃO GERAL

Este algoritmo é projetado para gerar todas as combinações possíveis de dois números (c1 e c2) 
que variam de 1 a 3. Ele faz isso usando dois laços aninhados (Para...faça), 
onde o primeiro laço controla o valor de c1 e o segundo laço controla o valor de c2. 
A cada iteração do laço interno, ele imprime a combinação atual de c1 e c2.

DECLARAÇÂO DE VARIÁVEIS:

var
   c1, c2: inteiro

c1 e c2: São as variáveis inteiras que serão usadas nos laços para gerar as combinações. 
Elas representam dois contadores que irão iterar sobre os valores de 1 a 3.

ESTRUTURA DO CÓDIGO:

inicio
    Para c1 <- 1 ate 3 faca
         Para c2 <- 1 ate 3 faca
            Escreval (c1, c2)
         FimPara
    FimPara
fimalgoritmo


PASSO A PASSO:

Laço Externo: Para c1 <- 1 ate 3 faca

O laço externo começa definindo a variável c1 com valor inicial de 1.
O laço executa enquanto c1 não exceder 3, incrementando c1 em 1 após cada iteração.
Então, o laço interno é executado para cada valor de c1.
Laço Interno: Para c2 <- 1 ate 3 faca

Para cada valor de c1, o laço interno inicia com c2 igual a 1.
Assim como o laço externo, c2 é incrementado de 1 até chegar a 3.
A cada iteração do laço interno, a combinação atual de c1 e c2 é exibida usando Escreval.
Impressão: Escreval (c1, c2)

Durante cada iteração do laço interno, o comando Escreval imprime os valores atuais de c1 e c2 na tela. Isso resulta na impressão de todas as combinações possíveis de c1 e c2 variando de 1 a 3.


RESULTADO ESPERADO:

O código irá gerar e imprimir as seguintes combinações:

1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

Explicação da Estrutura:

Laço Aninhado (Para dentro de outro Para):

O laço interno executa completamente para cada iteração do laço externo. Isso significa que, para cada valor de c1 (1, 2, 3), o laço c2 irá executar três vezes, 
gerando todas as combinações possíveis com c1 fixo.

Complexidade:

Como temos dois laços aninhados, cada com 3 iterações, o número total de combinações impressas será 3 x 3 = 9.

Conclusão
Este algoritmo é um exemplo simples de como usar laços aninhados para gerar combinações de valores. Ele é útil quando precisamos explorar todas as possíveis combinações de um conjunto de valores, neste caso, de 1 a 3.
